Connect

Drive it over HTTP

Standard OpenEnv loop — reset, then step until the case closes. Scored 0–1 (F1 + vector bonus − step penalty).

bash
# point at the deployed Space
$ BASE=https://deshan-5-supply-chain-forensics.hf.space

# start an episode
$ curl -X POST $BASE/reset \
    -H "Content-Type: application/json" \
    -d '{"task":"medium"}'

# take an investigative action
$ curl -X POST $BASE/step \
    -d '{"session_id":"...",
         "action":"check_maintainer",
         "params":{"name":"axios"}}'

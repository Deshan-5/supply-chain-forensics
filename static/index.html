The problem

The attack is never a known CVE. It emerges through behavior, context, and relationships — exactly what scanners miss.

The task

Given a project, a toolkit, and a limited step budget, the agent finds compromised packages and classifies how they got in.

Scored on

F1 for detection + a bonus for the right vector, minus a step penalty. Baselines land near 0.88–0.90.

04

Open a Session

Standard OpenEnv HTTP loop — reset, then step until the case closes.

bash
# point at the deployed Space
$ BASE=https://deshan-5-supply-chain-forensics.hf.space

# start an episode
$ curl -X POST $BASE/reset \
    -H "Content-Type: application/json" \
    -d '{"task":"medium"}'

# take an investigative action
$ curl -X POST $BASE/step \
    -d '{"session_id":"...",
         "action":"check_publish_history",
         "params":{"name":"axios"}}'
